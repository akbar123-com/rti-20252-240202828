# 02-literatur

Kumpulan referensi & paper terkait untuk mendukung Tinjauan Pustaka (Tahap 5) pada penelitian komparasi performa database untuk IoT .

## Topik referensi yang relevan

* Perbandingan kinerja database relasional (MySQL vs PostgreSQL).
* Metodologi pengujian beban (stress-testing / load testing) pada server.
* Sistem monitoring detak jantung real-time (IoT, mikrokontroler ESP32, Sensor MAX30102).
* Manajemen data IoT berfrekuensi tinggi (continuous streaming).

## Isi yang diharapkan

* Salinan/ringkasan paper (catatan ringkasan, anotasi, dan matriks perbandingan).
* Daftar pustaka terkumpul (format BibTeX/RIS) untuk diacu di `../07-manuskrip/`.

## Berkas

* `matriks-literatur.md` — matriks literatur lengkap (6 referensi utama yang memetakan *research gap*).
* `daftar-pustaka.bib` — bibliografi BibTeX (siap diimpor ke Mendeley/Zotero).
